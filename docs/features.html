lumora 功能详解

从文献入库到深度阅读，从全库检索到多设备同步。下面是 lumora 当前版本已经可用的全部功能，按使用场景分为九个部分。

文献库组织 PDF 阅读 高亮与笔记 元数据与 arXiv 全库检索 同步与集成 文件存储 界面与快捷键 平台支持
01 · 文献库组织

把成百上千篇论文理清楚

无限层级的文件夹、七个开箱即用的智能视图、按作者与标签筛选，以及两套互补的重复检测。

文件夹树

  • 任意层级嵌套，每个文件夹显示实时文档数，可折叠
  • 右键菜单：Add PDF、Add by arXiv ID、重命名、新建子文件夹、删除
  • 删除文件夹时子文件夹自动上提一级，夹内论文回落到父级，不会丢文档
  • 选中的论文所在的文件夹会高亮，一眼看出它被归到了哪里

七个智能视图

  • All Documents — 全部文献
  • Recently Added — 最近 7 天入库
  • No arXiv ID — 缺 arXiv 编号
  • No PDF — 尚无本地 PDF
  • Favorites — 已收藏
  • Unsorted — 未归入任何文件夹
  • All Deleted Documents — 回收站
  • 每个视图都带实时计数，缺 PDF、缺编号的文献一目了然

归类与筛选

  • 从列表拖拽论文到文件夹即可归入，一篇可同时属于多个文件夹
  • 右键 Move to 单夹移动；Remove from collection 移出当前夹
  • 侧栏可按作者、按标签折叠筛选，列表随选择即时收敛

回收站

  • 删除是软删除，进回收站后随时恢复到 Unsorted
  • 彻底删除会同时移除磁盘上的 PDF 与数据库记录
  • 回收站节点右键可 Empty Trash 一次清空

文档列表

  • 列：收藏星标、作者、标题、年份、发表于、入库时间
  • 点击列头排序并切换升降；列宽可拖拽或用键盘调整，设置会记住
  • 行虚拟化渲染，几千篇文献滚动依然顺滑
  • 每行显示 PDF 状态图标：本地已有 / 云端未下载 / 无文件

两套重复检测

  • Duplicate Documents — 按 PDF 的 SHA-256 把重复文献归组，显示各自所在文件夹路径，勾选保留一篇，其余移入回收站
  • 重复文件清理 — 扫描存储目录里内容相同的文件，保留被引用最多的那份，删除其余并把记录重新指向它，最后报告删除数量与释放空间
02 · PDF 阅读

为长时间阅读调优的渲染管线

双渲染引擎、页面虚拟化、按平台与显卡分级的渲染策略，以及会记住你读到哪里的阅读位置。

双渲染引擎

  • macOS 与 Windows 使用 PDF.js 渲染
  • Linux 走 Rust 原生渲染，底层调用 poppler，规避 WebKitGTK 的性能问题
  • 两条路径都有真实文本层，选中、复制、批注、查找一致可用

自适应渲染策略

  • 按运行环境分级：现代 WebKit、旧版 WebKit、Linux 独显 / 集显 / 软件渲染
  • 每一级各自决定最大设备像素比、画布像素上限、预渲染页数与缩放去抖
  • Linux 显卡等级由原生代码探测 DRM/sysfs 得出，不靠猜
  • 页面虚拟化：只挂载可见页与少量预渲染页，总高度由各页宽高比预先算出，滚动条不跳

缩放

  • 触控板双指捏合缩放（macOS 原生放大手势）
  • Ctrl + 滚轮无级缩放（macOS 上是 ⌃，不是 ⌘）
  • 菜单预设 75% / 90% / 100% / 110% / 125% / 150% / 175% / 200%
  • 按宽度适配 ⌘;，同时复位系统级放大

跳转与导航

  • 跳页 ⌘G，阅读器内弹出输入框
  • 点击 PDF 内部引用链接直接跳到对应位置
  • 返回上一位置 ⌘O 回到跳转前的滚动点，来回查引文不迷路
  • PDF 里的外部链接交给系统浏览器打开，仅放行 http/https

文档内查找

  • ⌘F 打开查找条，全文范围搜索
  • 显示命中计数（如「3 / 12」），无结果时明确提示
  • Enter / Shift+Enter 或按钮切换上下一个，当前命中单独高亮
  • Esc 关闭

阅读位置与多标签

  • 每篇论文各自记住滚动位置与缩放比例，退出时提交（含 macOS ⌘Q），重启原样恢复
  • 常驻 Documents 标签 + 每篇论文一个标签，可拖拽重排
  • ⌘1 回到列表，⌘2–⌘9 切到第 N 篇，⌘W 关闭当前标签
  • 大文件按需分段读取，不必先把整份 PDF 载入内存
03 · 高亮与笔记

批注不写进原始 PDF

全部标注以归一化坐标独立存储，原文件保持字节不变，随时可以拿去投稿或分享。

选中即标注

  • 选中文本弹出菜单：四种颜色、高亮、笔记、查看笔记、翻译、删除
  • 笔记 = 高亮 + 评论 + 一枚可拖动的便签图钉，放在你顺手的位置
  • 笔记可以退回成普通高亮，不必删了重画

坐标与原文保护

  • 标注存为 0–1 归一化矩形，缩放与换设备都不会错位
  • 同时保存被标注的原文引文
  • 每条标注记录来源文件的 SHA-256：文件被换成另一版时坐标自动隐藏，但引文与评论完整保留，不会画在错误的位置上

集中查看

  • 详情面板的 Notes 标签列出当篇全部高亮与笔记，可逐条删除
  • 笔记与引文内容进入全库检索，能直接搜到
  • 标注参与云同步与 Mendeley 双向同步
04 · 元数据与 arXiv

元数据尽量自动补齐

从 PDF 里抽、从 arXiv 上拉，改完元数据磁盘上的文件名跟着一起变。

详情面板

  • 可编辑：标题、arXiv ID、作者、年份、URL、标签、关键词、摘要、收藏
  • 显示已附的 PDF 文件名，右键可 Open Externally 用系统阅读器打开，或 Show in Folder 定位到文件
  • 一键 Google Scholar，按标题在浏览器里搜

从 PDF 提取

  • Extract PDF 一键抽取标题、作者、年份、摘要、关键词、DOI、arXiv ID
  • 先读 PDF 信息字典，再用首页版式启发式识别标题与作者，最后用文件名兜底
  • 识别出 arXiv 来源时自动把发表于设为 arXiv、类型设为预印本

arXiv 集成

  • Add by arXiv ID — 文件夹右键，输入编号即建条目并拉取元数据，也接受 arxiv.org/abs/… 链接
  • Search arXiv — 按标题搜索，从结果里挑一条回填元数据
  • Download from arXiv — 单篇下载，带字节级进度
  • Files → Download arXiv Files — 批量补齐所有缺 PDF 的文献，带整体进度提示
  • 编号锁定版本号（如 1706.03762v7），拿到的永远是元数据对应的那一版

文件命名模板

  • 模板变量 {title}、{year}、{author}，默认 {title}-{year}-{author}
  • 设置里实时预览生成的文件名
  • 自动处理非法字符、限制长度，重名自动加后缀（name-2.pdf）
  • 改完元数据，磁盘上的文件会自动重命名，库里库外始终对得上
05 · 全库检索

连 PDF 正文一起搜

基于 SQLite FTS5 的本地全文索引，标题、作者、笔记、PDF 正文都在检索范围内，中文可子串匹配。

索引结构

  • 两张 FTS5 虚拟表：一张放标题 / 作者 / 笔记，一张放 PDF 正文
  • 正文按文件 SHA-256 键入，换了文件才重新抽取
  • 正文抽取在后台进行，不阻塞阅读
  • 文献进回收站后索引保留，恢复时不用重跑一遍昂贵的正文抽取

中文检索

  • 中日韩文本在建索引与查询时都按单字切分，因此中文能像子串一样搜到
  • 西文使用 unicode61 分词并去变音符号
  • 输入会被安全地整体引用，特殊符号不会被当成检索语法

结果呈现

  • 每行标出命中字段：Title / Body / Authors / Notes
  • 给出高亮的上下文片段，不用点开就知道为什么命中
  • 默认按相关度排序，点列头即切回你自己的排序
  • 选中真实文件夹时，结果限定在该夹及其子夹；智能视图下搜全库

一个键两种含义

  • 在 Documents 列表页，⌘F 聚焦库内搜索框
  • 在论文阅读页，⌘F 打开文档内查找
  • Esc 清空搜索，输入有 200 毫秒去抖，边打边出结果不卡
06 · 同步与集成

你的数据，存在你自己的桶里

没有 lumora 服务器。云同步直连你自己的私有存储桶，密钥交给操作系统钥匙串保管。

七牛云 Kodo 私有桶同步

  • 无中间服务器：填自己的 AccessKey / SecretKey / 桶名 / 区域 / 私有域名，客户端直连；SecretKey 存操作系统钥匙串（macOS Keychain、Windows 凭据管理器、Linux Secret Service），不落盘
  • 协议 v1：protocol.json 元信息、按设备记录同步头、gzip 压缩的不可变变更批次、内容寻址的 blob 存储
  • 增量同步：按游标只拉新增变更；普通字段后写胜出，文件夹归属用 HLC 逻辑时钟版本与移动屏障保序，避免多端来回横跳
  • arXiv 来源的 PDF 不上传，同步的只是锁定版本的编号，需要时按编号重新下载，省流量也省空间
  • 指纹缓存（路径 / 大小 / 修改时间 / 哈希）与 24 小时 Stat 缓存，避免反复哈希和重复请求
  • 侧栏手动 Sync，也可开后台自动同步并设定间隔分钟数
  • 同步过程有实时进度卡，可随时取消；结束后汇总上传/下载条目数、字节数与各类请求次数
  • 保存配置时自动做一次连通性测试，也支持一键断开

Mendeley 双向同步

  • OAuth 授权：自行填入 Client ID 与 Secret，界面里有跳转到 Mendeley 应用注册页的入口
  • 文档、文件夹及其层级、归属关系、批注、回收站双向同步
  • 附件文件自动下载到本地
  • 首次全量之后转为增量，按修改 / 新增 / 删除时间拉取，自动翻页
  • 进度卡可取消；Mendeley 原有批注坐标被保留

划词翻译

  • 在 PDF 里选中文本，右键 Translate 查词
  • 就地显示音标与释义，可跳转到有道完整页面
  • 无需申请 API Key

网络代理

  • 支持 HTTP、HTTPS、SOCKS5、SOCKS5H
  • 可选代理账号密码
  • 15 秒连接超时，客户端按配置复用

自动更新

  • 启动时静默检查，也可从 Help → Check for Updates 手动查
  • 更新包经 minisign 签名校验，来源是 GitHub Release
  • 展示发布说明与下载进度，安装完提示重启生效，失败可重试

代理的作用范围：Mendeley 同步、arXiv 搜索与下载、划词翻译、更新检查会走你配置的代理。七牛云同步使用独立的网络客户端，不受该代理设置影响。

07 · 文件存储

PDF 放在你指定的目录里

文献库目录就是事实来源，文件名可读、可被其它工具管理，不锁在应用的私有数据库里。

外部文献库目录

  • 用系统目录选择器指定一个文件夹，PDF 全部落在那里，按命名模板取名
  • 更换目录时自动迁移已有的全部 PDF
  • 未配置目录时文件留在应用数据库内，随时可以再迁出来

与外部改动共存

  • Files → Refresh Library（⌘R）重新读库并重读文件，感知你在 Finder 里做的改动
  • Open Externally / Show in Folder 直达系统阅读器与文件管理器
  • 存文件时自动避让重名，文件名经过校验，不会写到目录之外

库数据本身

  • 元数据、文件夹、批注存本地 SQLite（WAL 模式）
  • 写入去抖并与上次持久化状态做差分，只写真正变了的部分
  • 全部数据在本机，离线可用
08 · 界面与快捷键

三栏工作区，双手不离键盘

面板宽度、打开的标签、每篇论文读到哪里，关掉再开都还在。

三栏布局

  • 文献库 | 工作区 | 详情，三栏各自可拖拽调宽
  • 侧栏可折叠，折叠后留一条可点开的窄边
  • 宽度与折叠状态持久保存；⌘J 开关左栏，⌘I 开关右栏

会话恢复

  • 重启后还原打开的标签、当前标签、选中的文件夹与论文
  • 每篇 PDF 的滚动位置与缩放一并还原
  • 恢复的论文标签首次点开才真正加载，避免启动时一次性吃满资源
  • 窗口大小、位置、最大化状态也会记住

原生应用菜单

  • Files — Refresh Library、File Storage Settings、Download arXiv Files、Duplicate Documents
  • View — 返回上一位置、按宽度适配、缩放预设、跳页、全屏
  • Window — 最小化、最大化、关闭标签
  • Help — 检查更新、快捷键一览
  • 应用菜单内还有 Mendeley 同步、同步设置、代理设置与关于

状态与容错

  • 工具栏状态行、arXiv 批量下载浮层、同步进度卡实时反馈当前动作
  • 渲染异常有错误边界兜住，不会整窗白屏
  • 关于窗口显示版本号、构建时间与 git 提交指纹，报问题时可直接对号

完整快捷键

快捷键作用场景
⌘1切到 Documents 列表全局
⌘2 – ⌘9切到第 2–9 个打开的论文标签全局
⌘W关闭当前标签全局
⌘F库内搜索 / 文档内查找（随当前标签切换）全局
Enter / Shift+Enter下一个 / 上一个查找命中查找条
⌘G跳转到指定页阅读器
⌘;按窗口宽度适配阅读器

09 · 平台支持

三平台，各自用原生方案

当前开发重心是 macOS，其次 Linux。各平台的密钥存储与 PDF 渲染都走系统原生能力。

平台安装包PDF 渲染密钥存储平台特有
macOS DMG（Apple Silicon 与 Intel 各一份） PDF.js Keychain 触控板捏合缩放、原生菜单约定、⌘Q 退出前保存阅读进度
Linux .deb 与 AppImage 原生 poppler 渲染 Secret Service 需 WebKitGTK 与 libsecret；按显卡等级分级的渲染策略；需安装 poppler-utils
Windows MSI 与 NSIS 安装器 PDF.js 凭据管理器 更新以静默模式安装

Linux 上若未安装 poppler-utils，阅读器会提示安装后重启；deb / rpm 包已把它声明为依赖。
