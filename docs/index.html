高效管理与深度阅读

lumora 取意 Lumos + Aurora，一款本地优先的桌面文献管理应用，覆盖 PDF 导入、高亮批注、文献集合组织与私有云同步等完整研究文献工作流。数据存储于本地，密钥依托操作系统钥匙串，兼顾效率与隐私。

核心功能

为深度阅读而生

从导入到批注，从整理到同步，lumora 覆盖研究文献工作流的每一环。

PDF 导入与多标签阅读

一键导入 PDF，元数据与文件本地存储。以标签页形式同时打开多篇论文，快捷键在文档间自由切换。

右键高亮与笔记

选中文本即可创建高亮或笔记，采用归一化坐标标注，全程不修改原始 PDF，安全无损。

文献集合管理

侧边栏集合分组整理论文，配合按文件夹范围的库内检索与文档内查找，快速定位你需要的每一篇文献。

私有云同步

基于原生 Tauri 同步引擎，直连你自己的私有七牛云 Kodo 存储桶，增量同步；密钥存于操作系统钥匙串，绝不落盘。

Mendeley 导入

通过 OAuth 连接 Mendeley，增量导入文献元数据与文件夹结构，让原有文献库平滑迁移到 lumora。

键盘快捷键

为阅读优化的快捷键：文档内查找、按宽度适配、页面缩放与跳转、侧栏与同步面板开关，双手不离键盘。

快速开始

三步开始使用

下载即用，或从源码构建你自己的版本。

1

下载安装

前往 Releases 页面 下载对应平台（macOS / Linux / Windows）的最新版本，或克隆仓库执行 npm install 从源码构建。

2

导入并阅读

导入 PDF 或从 Mendeley 迁移文献，开始右键批注、整理集合，并在多台设备间同步。

3

配置云同步

在同步面板中填入私有七牛云 Kodo 的 AccessKey、SecretKey、桶名与私有下载域名，一个桶托管一个文献库。

开始使用 lumora
